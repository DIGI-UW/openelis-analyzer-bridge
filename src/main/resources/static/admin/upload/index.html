Analyzer File Upload — Bridge Admin

Drop a real analyzer result file into a registered FILE analyzer's watched directory and declare the test code at upload time. The bridge parser validates the declaration against the file's content via the file-level self-declaration scanner (no persistent per-analyzer defaults — test identity must come from the file + tech).

Only test codes configured on the selected analyzer (via its AnalyzerTestMapping set from the profile) can be chosen. The bridge will re-validate your choice against the file's content before processing.
